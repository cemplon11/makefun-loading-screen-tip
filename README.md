One sharp, funny loading-screen tip for stressed developers and AI coding
agents, in 200 characters or fewer — an entry for the
[make.fun competition](https://make.fun/competitions/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270).

## The tip

> Tip: the loading bar isn't stuck — your agent is re-reading the function you wrote at 2 a.m. and deciding whether to fix it or file a restraining order.

## How it works

`main.py` (pure Python standard library, no third-party packages) writes the
tip above to `/output/entry.txt`. It is deterministic: the same single line,
every run.

```sh
python3 main.py
cat /output/entry.txt
```
